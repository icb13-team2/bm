# 데이터_다운캐스트

쇼핑 라벨링 데이터(JSON 7개)를 downcast + category 변환 + parquet 저장하고, tidy(long form) 표로 정리한 작업이에요.

- 보고서: `report/` (`00_팀원공유_진행사항.md`부터 읽어 주세요)
- 스크립트: `src/`
- 이 저장소에는 원문이 들어간 데이터(원본 JSON, zip, parquet)를 올리지 않았어요. `data/` 폴더는 `.gitignore`로 막아 두었어요.
- 데이터를 다시 만들려면 `쇼핑_라벨링데이터.zip`이 `데이터_다운캐스트/` 바로 위 폴더에 있어야 해요.
