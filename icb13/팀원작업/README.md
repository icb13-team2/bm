# 팀원 작업 폴더

팀원마다 분석 결과를 따로 올리고, 서로 비교하기 위한 폴더예요.

## 올리는 방법

1. 이 폴더 안에 내 이름으로 폴더를 만들어요. 예: `icb13/팀원작업/홍길동/`
2. 분석 결과를 그 폴더에 올려요. 보고서, 표, 그림, 스크립트가 좋아요.
3. 다른 팀원의 폴더는 고치지 않아요. 읽고 비교만 해요.
4. 비교할 때는 같은 기준끼리 맞춰 보세요. 기준이 다르면 이유를 README에 적어 주세요.

## 폴더 구조 예시

```
icb13/팀원작업/
├── README.md
└── 이름/
    ├── README.md      # 무엇을 했는지 짧게
    ├── report/        # 보고서, 표
    └── src/           # 스크립트
```

## 올리면 안 되는 것

이 저장소는 공개예요. 원문이 들어간 파일은 올리지 마세요.

- 상담 원문 데이터 (`zip`, `json`, `parquet`, `csv` 등)
- 원문이 들어간 대시보드와 뷰어 (HTML, JS 데이터 파일)
- 원문 문장을 그대로 붙여 넣은 보고서와 엑셀

AI-Hub 이용약관 확인이 끝나기 전까지는 라벨, ID, 숫자만 올려요.
