# bm

쇼핑 상담 데이터를 분석하는 팀2의 작업 저장소예요.
챗봇 대화에서 턴 수가 길어지는 신호를 찾아, 상담사 전환에 쓰는 것이 목표예요.

## 폴더 구조

```
icb13/
├── 데이터_다운캐스트/    # 데이터 줄이기와 tidy 변환 (보고서, 스크립트)
│   ├── report/          # 진행사항과 변환 보고서
│   └── src/             # 변환과 조회 도구 스크립트
└── 팀원작업/            # 팀원별 분석 결과
    └── 이름/            # 예: jy, se, kr
```

처음 보는 분은 `icb13/데이터_다운캐스트/report/00_팀원공유_진행사항.md`부터 읽어 보세요.

## 팀원 작업 규칙

1. `icb13/팀원작업/` 아래 내 이름 폴더에 결과를 올려요.
2. 다른 팀원 폴더는 고치지 않고, 읽고 비교만 해요.
3. 비교할 때는 같은 기준끼리 맞추고, 기준이 다르면 이유를 적어 주세요.
4. 작업은 새 브랜치에서 하고, PR로 main에 합쳐요.

자세한 안내는 `icb13/팀원작업/README.md`에 있어요.

## 원문 파일은 올리지 않아요

이 저장소는 공개예요. 아래 파일은 올리지 마세요.

- 상담 원문 데이터 (`zip`, `json`, `parquet`, `csv` 등)
- 원문이 들어간 대시보드와 뷰어 (HTML, JS 데이터 파일)
- 원문 문장을 그대로 붙여 넣은 보고서와 엑셀

AI-Hub 이용약관 확인이 끝나기 전까지는 라벨, ID, 숫자만 올려요.
